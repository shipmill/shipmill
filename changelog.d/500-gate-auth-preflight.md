### Fixed

- Gate: a lost Claude Code login no longer burns the retry window. Before a launch the gate runs `claude auth status --json`, and when Claude Code isn't logged in it starts no session and reports `CLAUDE_AUTH` with the fix (`claude auth login`), sending one desktop notification per failure episode with `[agents] notify = true`; `doctor` checks the login too. A headless session that ended within 60 seconds of its launch (by its log's last write) or whose log holds an authentication failure doesn't count toward `retry_hours`: the next tick launches again and reads `SESSION_DEAD`, naming the dead session, how many died in a row, and its log's last line. `shipmill status` reports both, and github-ship-watch's `watch_state.py` reports a gate whose sessions end dead as `GATE_SESSIONS_DEAD` (#500)
